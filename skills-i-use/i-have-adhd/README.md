# i-have-adhd

**Source:** https://github.com/ayghri/i-have-adhd (MIT)

Shapes Claude's answers for a reader with ADHD: the next action first, numbered steps, no side topics, short answers to short questions.

## Why I use it
- Answers start with what to do, not with background.
- Long replies become short numbered steps I can act on straight away.

## Install

```bash
claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd
```

Say "stop adhd mode" to turn it off for a session.
